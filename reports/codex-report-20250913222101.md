## Reasoning
The Python preprocessing uses pandas to load every column as `object` and then applies a series of custom column transforms before writing back to CSV. The TypeScript helper must preserve raw string values to allow similar transformations later in the pipeline and offer a mechanism to apply row-level transforms.

## Plan for P1T2
1. Implement `loadCsv` that accepts a `File` or string and parses it in the browser using a library like `PapaParse`, producing `Record<string,string>[]` without type coercion.
2. Expose a `CsvTransform` type and helper to apply an array of transforms immutably to the parsed records, enabling operations akin to Python's `column_split`.
3. Provide error handling for malformed CSVs and missing headers so downstream tasks can surface clear messages.
4. Create unit tests and a test script to validate parsing, transforms, BOM handling, and empty line skipping.
